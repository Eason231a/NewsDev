# 黑马头条自媒体人管理系统 - 产品需求文档

## 产品概述

### 产品定位
黑马头条是一款面向自媒体创作者的内容管理与数据分析平台，帮助创作者管理发布的内容、分析数据表现、管理素材和粉丝。

### 目标用户
自媒体创作者、内容运营人员

### 产品架构
```
黑马头条
├── 登录系统
├── 图文数据（数据概览 + 文章详情）
── 发布文章（内容创作与发布）
├── 内容列表（内容管理与状态控制）
├── 素材管理（图片资源管理）
└── 粉丝管理（粉丝概况 / 粉丝画像 / 粉丝列表）
```

## 功能模块详述

### 登录模块

#### 页面说明
- 登录页面包含左侧品牌展示区和右侧登录表单区
- 左侧展示"欢迎使用 黑马头条自媒体人管理系统"及品牌插图
- 右侧为登录表单

#### 功能需求
| 字段/元素 | 说明 |
|---------|------|
| 用户名 | 文本输入框，必填 |
| 密码 | 密码输入框，必填 |
| 用户协议 | 复选框，勾选"我已阅读并同意用户协议和隐私政策条款" |
| 登录按钮 | 点击后提交登录请求 |

#### 交互规则
- 未勾选用户协议时，登录按钮不可点击或提示需先同意协议
- 登录成功后跳转至图文数据列表页

### 图文数据模块

#### 图文数据列表页

**页面布局：**
- 顶部：数据时间筛选区 + 快捷日期选择
- 中部：4个核心数据统计卡片
- 底部：文章数据列表 + 分页

**数据时间筛选：**
| 元素 | 说明 |
|------|------|
| 开始日期 | 日期选择器，点击弹出日期选择面板 |
| 结束日期 | 日期选择器，点击弹出日期选择面板 |
| 今日 | 快捷按钮，点击后时间范围设为当天 |
| 本周 | 快捷按钮，点击后时间范围设为本周 |
| 近7天 | 快捷按钮（默认选中），点击后时间范围设为近7天 |
| 近30天 | 快捷按钮，点击后时间范围设为近30天 |

**统计卡片（4项）：**
| 指标 | 说明 |
|------|------|
| 图文发布量 | 统计周期内发布的图文总数 |
| 点赞数量 | 统计周期内获得的点赞总数 |
| 收藏数量 | 统计周期内获得的收藏总数 |
| 转发数量 | 统计周期内获得的转发总数 |

**数据列表：**
| 列名 | 说明 |
|------|------|
| 序号 | 自动编号 |
| 文章名称 | 文章标题 |
| 阅读 | 阅读量 |
| 评论量 | 评论数 |
| 收藏量 | 收藏数 |
| 转发量 | 转发数 |
| 操作 | "详细分析"链接，点击跳转至文章数据详情页 |

**分页功能：**
- 显示总条数、每页条数
- 支持翻页（上一页、下一页、页码跳转）
- 默认每页10条

#### 文章数据详情页

**页面布局：**
- 顶部：返回按钮 + 数据时间筛选（同列表页）
- 中部：8个数据统计卡片（分两行，每行4个）
- 底部：2个图表分析区域

**统计指标（第一行）：**
| 指标 | 说明 |
|------|------|
| 平均阅读进度 | 用户平均阅读完成百分比 |
| 跳出率 | 用户进入后直接离开的比例 |
| 平均阅读时间 | 用户平均停留时长（秒） |
| 推荐转发量 | 通过推荐渠道的转发量 |

**统计指标（第二行）：**
| 指标 | 说明 |
|------|------|
| 评论量 | 该文章的评论总数 |
| 总阅读量 | 该文章的总阅读次数 |
| 粉丝阅读量 | 来自粉丝的阅读次数 |

**图表分析：**
| 图表 | 说明 |
|------|------|
| 阅读来源分析 | 环形图展示各来源占比（推荐、频道、相关阅读、应用外阅读、其他） |
| 阅读完成度分析 | 环形图展示阅读完成度分布（20%以下、20%-80%、80%以上） |

### 发布文章模块

#### 页面说明
文章创作与发布页面，支持富文本编辑、标签设置、频道选择、定时发布、封面设置等功能。

#### 功能需求

**富文本编辑器工具栏：**
| 工具 | 说明 |
|------|------|
| 加粗 | 文本加粗格式 |
| 斜体 | 文本斜体格式 |
| 下划线 | 文本下划线格式 |
| 标题 | 插入标题格式 |
| 引用 | 插入引用块 |
| 有序列表 | 插入有序列表 |
| 无序列表 | 插入无序列表 |
| 插入图片 | 点击弹出素材选择弹窗，支持从素材库选择或本地上传 |
| 左对齐 | 文本左对齐 |
| 居中 | 文本居中对齐 |
| 右对齐 | 文本右对齐 |

**插入图片弹窗：**
| 元素 | 说明 |
|------|------|
| 标签页切换 | "素材库"（默认）和"本地上传"两个标签页 |
| 左侧筛选 | "全部"和"收藏"两个筛选选项 |
| 图片网格 | 展示素材图片，支持单选（点击选中，右上角显示勾选标记） |
| 分页信息 | 显示总条数、每页条数、页码跳转 |
| 取消按钮 | 关闭弹窗，不插入图片 |
| 确定按钮 | 将选中的图片插入到编辑器光标位置 |

**编辑区域：**
| 元素 | 说明 |
|------|------|
| 标题输入框 | 单行文本输入，输入文章标题 |
| 正文编辑区 | 富文本编辑区域，输入文章正文内容 |

**提交参数说明：**
| 字段 | 类型 | 说明 |
|------|------|------|
| title | String | 文章标题 |
| content | JSON String | 文章正文，以JSON字符串格式提交，包含富文本格式信息和图片链接等 |
| tags | String | 标签，逗号分隔 |
| channel_id | Long | 频道ID |
| cover_type | String | 封面类型：single/three/none |
| cover_images | Array | 封面图片URL数组（单图时1个元素，三图时3个元素） |
| scheduled_publish_at | DateTime | 定时发布时间（可选） |

**表单配置：**
| 字段 | 说明 | 规则 |
|------|------|------|
| 标签 | 文本输入框 | 最多20个字符，显示字符计数（0/20） |
| 频道 | 下拉选择框 | 选择文章所属频道 |
| 定时 | 日期时间选择器 | 选择发布日期和时间，支持年月日时分秒选择 |
| 封面 | 单选按钮组 | 可选：单图（默认）、三图、无图 |
| 封面图片 | 图片上传区域 | 点击上传封面图片 |

**操作按钮：**
| 按钮 | 说明 |
|------|------|
| 存入草稿 | 保存为草稿状态，不提交审核 |
| 提交审核 | 提交文章进入审核流程 |

#### 交互规则
- 封面选择为"单图"时，显示单图上传区域
- 封面选择为"三图"时，显示三图上传区域
- 封面选择为"无图"时，隐藏图片上传区域
- 定时发布：选择时间后，文章将在指定时间自动发布

### 内容列表模块

#### 页面说明
管理所有已创建的文章内容，支持按状态筛选、搜索、上下架操作。

#### 功能需求

**状态筛选（单选）：**
| 状态 | 说明 |
|------|------|
| 全部 | 显示所有状态的文章 |
| 草稿 | 仅显示草稿状态的文章 |
| 待审核 | 仅显示待审核状态的文章 |
| 审核通过 | 仅显示审核通过的文章 |
| 审核失败 | 仅显示审核失败的文章 |

**筛选条件：**
| 条件 | 说明 |
|------|------|
| 关键字搜索 | 按文章标题或内容关键字搜索 |
| 频道筛选 | 按频道筛选文章 |
| 日期范围 | 按创建日期范围筛选 |

**文章卡片展示：**
每篇文章以卡片形式展示，包含：
- 封面图片
- 文章标题
- 创建日期
- 状态标签

**状态标签：**
| 标签 | 颜色 | 说明 |
|------|------|------|
| 草稿 | 灰色 | 未提交的文章 |
| 待审核 | 橙色 | 已提交等待审核 |
| 审核通过 | 绿色 | 审核通过，可上架 |
| 审核失败 | 红色 | 审核未通过 |
| 已上架 | 蓝色 | 已发布且在线 |
| 已下架 | 灰色 | 已发布但已下架 |

**操作按钮（悬停显示）：**
| 状态 | 可用操作 |
|------|---------|
| 草稿 | 编辑、删除 |
| 已发表且已上架 | 下架 |
| 已发表且已下架 | 上架 |
| 待审核 | 无操作按钮 |
| 审核失败 | 编辑、删除 |

### 素材管理模块

#### 页面说明
管理已上传的图片素材，支持上传、收藏、删除、筛选等功能。

#### 功能需求

**标签页切换：**
| 标签 | 说明 |
|------|------|
| 全部 | 显示所有已上传图片 |
| 收藏 | 仅显示已收藏的图片 |

**顶部信息：**
- 显示已上传图片总数（如"已上传40张图片"）
- "上传图片"按钮，点击弹出上传弹窗

**上传图片弹窗：**
| 元素 | 说明 |
|------|------|
| 选择图片区域 | 虚线框区域，点击选择本地图片文件 |
| 格式说明 | 支持扩展名：jpg、png，文件不得大于2MB |
| 开始上传按钮 | 选择图片后变为可点击，点击开始上传 |
| 上传进度 | 显示上传进度条 |
| 关闭按钮 | 关闭弹窗 |
| 确定按钮 | 上传完成后关闭弹窗 |

**素材卡片：**
每个素材卡片包含：
- 图片预览
- 收藏按钮（☆ 收藏 / ★ 已收藏）
- 删除按钮

**收藏功能：**
- 点击"☆ 收藏"变为"★ 已收藏"，图片加入收藏列表
- 点击"★ 已收藏"取消收藏，恢复为"☆ 收藏"

**删除功能：**
- 点击删除按钮，确认后删除该素材

**分页功能：**
- 显示总条数、每页条数
- 支持翻页

## 全局功能

### 侧边栏导航

| 菜单项 | 图标 | 跳转页面 |
|--------|------|---------|
| 图文数据 | 📊 | 图文数据列表页 |
| 发布文章 | ✏️ | 发布文章页 |
| 内容列表 | 📄 | 内容列表页 |
| 素材管理 | 🖼️ | 素材管理页 |
| 粉丝管理 |  | 粉丝管理-粉丝概况页 |

**交互规则：**
- 当前页面对应的菜单项高亮显示（蓝色背景）
- 点击菜单项跳转到对应页面
- 底部显示当前登录用户信息（头像 + 用户名）

### 日期选择器

**通用日期选择器：**
- 点击日期输入框弹出日期选择面板
- 面板显示在输入框正下方
- 支持切换年/月
- 点击日期选中并回填到输入框
- 点击外部区域或取消按钮关闭面板

**日期时间选择器（发布文章-定时）：**
- 包含日期选择 + 时/分/秒三列滚动选择
- 选择完成后点击确定回填完整日期时间

### 分页组件

- 显示总条数和每页条数
- 支持上一页、下一页、页码跳转
- 支持输入页码直接跳转

## 非功能性需求

### 性能要求
- 页面加载时间不超过3秒
- 数据列表分页加载，每页默认10条

### 兼容性要求
- 支持主流浏览器（Chrome、Firefox、Safari、Edge）
- 推荐分辨率：1920×1080及以上

### 安全性要求
- 登录密码加密传输
- 用户协议和隐私政策需用户确认后生效
- 敏感操作（删除、拉黑）需二次确认
